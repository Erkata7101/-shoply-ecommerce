Shoply — E-commerce Website

Shoply is a modern e-commerce web application built to provide a simple and convenient online shopping experience.
Status: In Development 
Features
Responsive shopping homepage.
Product browsing and search.
Product categories and details.
Shopping cart and wishlist.
Customer registration and login.
Checkout and order management.
Admin product management.
Features are being implemented progressively.
Technologies
Frontend: React, JavaScript, CSS3, Vite
Tools: Git, GitHub, ESLint
